# EA-G04-Camposol
# Arquitectura Empresarial — Proyecto TOGAF

## Descripción

Repositorio académico colaborativo del curso de Arquitectura Empresarial, orientado al análisis y diseño de la arquitectura de Camposol mediante el marco TOGAF y el método ADM.

## Objetivo general

Desarrollar una propuesta de arquitectura empresarial que permita alinear los procesos de negocio, los sistemas de información y la infraestructura tecnológica con los objetivos estratégicos de la organización.

## Metodología

Se utilizará TOGAF ADM como metodología de referencia, adaptando sus fases y entregables al alcance del proyecto académico.


## Herramientas

- GitHub: control de versiones y colaboración.
- ArchiMate: modelado de arquitectura empresarial.
- BPMN: modelado de procesos de negocio.
- Markdown: documentación técnica.
